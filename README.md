# Project Details

## Project Title: School Event Management System

## Problem Statement:
Many schools and universities struggle to organize events clearly for students. Information about club events, department-based seminars, conferences, and mentorship opportunities is often scattered across different places, making it difficult for students to find relevant events on time. Students may miss important activities because there is no centralized system that separates events by department, student clubs, and user role.

## Proposed Solution:
Our proposed solution is a School Event Management System that helps students easily discover and manage events in one place. The system will support multiple roles such as Admin, Student, and Student Club President. Students will be able to view event timetables based on their department and clubs, while club presidents and admins will manage and organize events. The system will also allow students to apply for mentorship opportunities from student mentors.

## Project Scope:
- Aim: To develop a web-based system that centralizes school event management and mentorship opportunities for students, clubs, and administrators.
- Objectives:
  1. To provide students with a clear timetable of events based on their department and club membership
  2. To allow admins to manage all users, events, and system data
  3. To allow student club presidents to create and manage club-related events
  4. To help students discover seminars, conferences, and school activities more easily
  5. To allow students to apply for mentorship from student mentors
  6. To improve communication and organization between departments, clubs, and students

## Application Description:
The School Event Management System is a role-based application designed for educational institutions.
